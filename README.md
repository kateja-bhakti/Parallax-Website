# 🌄 Parallax Website

A modern and responsive **Parallax Scrolling Website** built using **HTML** and **CSS**. This project demonstrates the classic parallax scrolling effect with full-screen sections, immersive background images, and a clean, modern user interface.

---

## ✨ Features

* 🌟 Classic parallax scrolling effect
* 📱 Responsive design for desktop, tablet, and mobile
* 🖼️ Full-screen background images
* 🌑 Dark overlay for improved text readability
* 🎨 Modern typography and elegant layout
* 🚀 Smooth user experience
* 🔗 Call-to-action portfolio button

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Design
* CSS Pseudo-elements

## 🚀 Getting Started

1. Clone the repository

```bash
https://github.com/kateja-bhakti/Parallax-Website.git
```

2. Navigate to the project folder

```bash
cd parallax-website
```

3. Open `index.html` in your browser

or

Run the project using the **Live Server** extension in Visual Studio Code.
